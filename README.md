## ChemShaa Live Lobby

A real-time "LIVE NOW" waiting room experience built for high engagement during broadcast events. The application features a dark canvas centered around a dynamic, pulsating radar emitter, clear call-to-action typography, and an interactive "Tune In" entry point


## Key Features
Pulsing Visual Emitter: A multi-layered, concentric radar visual built with Framer Motion that scales and shifts opacity in a continuous infinite loop.  

ChemShaa Header: A top navigation bar featuring high-contrast brand styling and action controls.  

Action Controls: High-visibility "LIVE NOW" messaging paired with micro-animated CTA buttons.  Real-time State Hook (useLobbyState): Decoupled UI state handling simulated WebSocket/SSE events for participant counts and stream status updates.  

Mobile-First & Fully Responsive: Responsive viewport locking designed to deliver an optimal experience on mobile devices while staying centered on desktop screens.
